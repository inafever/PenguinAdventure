# 🐧 펭귄의 북극 모험

초등학교 4학년도 바로 할 수 있는 **가로 장애물 피하기** 게임입니다.

## 바로 하는 방법

1. `index.html` 파일을 **더블클릭**해서 브라우저로 엽니다.
2. **시작하기**를 누릅니다.
3. **스페이스바**, **위쪽 화살표**, **마우스 클릭**, **터치**로 점프합니다.
4. 얼음, 북극곰, 북극늑대, 사냥꾼을 뛰어넘으세요.
5. 물고기를 먹으면 점수가 더 올라갑니다.

## 게임 속에 있는 것

- 펭귄 주인공
- 북극 하늘, 오로라, 눈, 얼음 땅
- 장애물: 얼음 / 북극곰 / 북극늑대 / 사냥꾼(그물)
- 점프해서 넘을 수 있는 얼음
- 얼음 구멍에서 튀어 오르는 물고기 모으기, 점수, 최고 기록
- 1~5단계: 얼음 평원 → 북극곰 마을 → 늑대 마을 → 사냥꾼의 기지 → 목적지
- 단계마다 배경이 달라져요 (평원, 북극곰 마을, 늑대 마을, 사냥꾼의 기지, 목적지)

작은 팁: 진짜 펭귄은 남극에 살아요. 이 게임은 **상상의 북극 모험**입니다!

## 다음에 넣어보면 좋은 아이디어

1. **두 번 점프**(더블 점프) — 높은 장애물도 넘기 쉬워져요.
2. **미끄러지기** — 숙여서 높은 장애물 아래로 지나가기.
3. **보호막** — 별이나 아이템을 먹으면 한 번 버틸 수 있어요.
4. **낮/밤 바꾸기** — 밤에는 오로라가 더 예쁘게.
5. **펭귄 옷 고르기** — 빨간 목도리, 산타 모자 같은 스킨.
6. **소리와 음악** — 점프 소리, 북극 바람 소리.
7. **펭귄 옷 고르기** — 산타 모자 같은 스킨.

## 직접 만들고 싶다면

가장 쉬운 순서는 이렇게 추천해요.

1. **스크래치(Scratch)** — 블록을 끼워 게임을 만들 수 있어요. 코딩을 처음 배울 때 최고입니다.
2. **이 폴더의 HTML 게임** — 브라우저만 있으면 되고, `game.js`를 조금씩 고쳐 볼 수 있어요.
3. **나중에 유니티(Unity)** — 더 큰 3D 게임을 만들고 싶을 때.

`game.js`에서 바꿔 보면 재미있는 숫자:

- `JUMP = -13.5` → 숫자를 **-16**처럼 더 작게(더 크게 점프)
- `GRAVITY = 0.62` → 숫자를 줄이면 천천히 떨어짐
- `speed = 6` → 시작 속도
